# 🧭 Especificación General: Riqsi Rutas

## Visión General
**Riqsi Rutas** es una aplicación interactiva enfocada en la planificación y optimización de trayectos de transporte y rutas turísticas. Utiliza estructuras de datos avanzadas (Grafos, Dijkstra) y servicios web en tiempo real.
